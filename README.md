# Kingdom Hearts Save Editor: Keyblade

A browser-based save editor and transfer tool for the PC versions of the Kingdom Hearts Final Mix collection.

## Current support

- Kingdom Hearts Final Mix
  - Levels, synchronized stats, EXP, abilities, Munny, and farmable inventory
- Re:Chain of Memories
  - Moogle Points and non-story card inventory
- Kingdom Hearts II Final Mix
  - Synchronized party progression, Munny, and farmable inventory
- Birth by Sleep Final Mix
  - Save transfer only; editing is planned

Steam and Epic Games Store save archives are supported.

## Using the editor

1. Back up your original save.
2. Upload the save archive.
3. Edit a slot or transfer selected entries.
4. Download the newly created save.

All processing happens locally in your browser. Saves are not uploaded to a server.
